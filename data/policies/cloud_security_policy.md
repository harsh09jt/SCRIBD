# Cloud Security and Governance Policy
Document ID: POL-SEC-015
Version: 2.6
Last Updated: 2026-05-27
Department: Cybersecurity
Owner: Head of Cloud Security
Access Roles: employee, manager, hr, legal, admin

## 1. Approved Cloud Use
Only approved cloud providers and services may hold Acme data. New cloud services need a security review before purchase. Data residency requirements in contracts and law must be respected.

## 2. Configuration Baselines
Storage must not be public unless approved by the CISO. All cloud resources must be tagged with owner and data classification, use least-privilege IAM roles, and have logging turned on. Infrastructure is deployed through code with automated policy checks.
