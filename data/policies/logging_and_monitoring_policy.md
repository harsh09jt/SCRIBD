# Security Logging and Monitoring Policy
Document ID: POL-SEC-018
Version: 2.2
Last Updated: 2026-06-08
Department: Cybersecurity
Owner: Head of Security Operations
Access Roles: employee, manager, hr, legal, admin

## 1. What Is Logged
Authentication events, privileged actions, access to confidential data, network security events and configuration changes are logged and sent to the central SIEM.

## 2. Retention and Review
Security logs are retained for 13 months (12 months searchable). Alerts are triaged by the SOC 24/7, and privileged access logs are reviewed monthly. Logs are protected from alteration.
